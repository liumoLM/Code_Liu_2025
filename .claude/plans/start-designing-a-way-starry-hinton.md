# Standalone Overview-Table Vignette

## Context

The main vignette (`vignette/vignette.qmd`) opens with an interactive overview
table that lists every InsDel signature and its closest matches in COSMIC, Koh,
and Jin et al. catalogs. Each signature ID in that table is rendered as an
anchor link (`<a href="#insdel1a">…</a>`) that jumps to the per-signature
section *within the same HTML document*.

Per-signature HTML pages already exist as standalone files under
`vignette/figure/separate_pages/` (44 files, e.g. `InsDel1a.html`,
`InsDel_A_alpha.html`), generated by `vignette/render_separate_pages.R` from
`vignette/onesig_standalone.qmd`.

We want a *third* artifact: a standalone "overview" vignette that contains
**only** the table and whose signature-ID hyperlinks point at the matching
file under the separate-pages directory. The directory path should be a
parameter so the caller can choose a relative or absolute location (e.g. for
deployment to a different folder on a server).

## Design

### 1. Parameterize the hyperlink builder

Currently `vhelpers.R::make_sig_hyperlink()` (vhelpers.R:65) always emits an
in-page anchor:

```r
make_sig_hyperlink <- function(sig_id) {
  paste0('<a href="#', tolower(sig_id), '">', format_signature_name(sig_id), '</a>')
}
```

Add an optional `link_base` argument. When `NULL` (current behavior) emit an
anchor link; when a directory string is given, emit a link to the standalone
file using the same `safe_name` convention as `render_separate_pages.R:329`:

```r
make_sig_hyperlink <- function(sig_id, link_base = NULL) {
  display_name <- format_signature_name(sig_id)
  if (is.null(link_base)) {
    href <- paste0("#", tolower(sig_id))
  } else {
    safe_name <- gsub("[^a-zA-Z0-9_]", "_", sig_id)
    href <- file.path(link_base, paste0(safe_name, ".html"))
  }
  paste0('<a href="', href, '" target="_blank">', display_name, '</a>')
}
```

`target="_blank"` is harmless for the in-page case and useful for the new one;
if it changes the existing behavior in `vignette.qmd` we will gate it on
`!is.null(link_base)`.

### 2. Parameterize `create_overview_table()`

Add a `link_base = NULL` argument to `create_overview_table()`
(vhelpers.R:1444) and forward it to `make_sig_hyperlink()` at
vhelpers.R:1530. The existing call at vignette.qmd:519 keeps working
unchanged (defaults to `NULL`).

### 3. New Quarto document: `vignette/overview_table_standalone.qmd`

Minimal, self-contained document — no recomputation. It reads the already
saved `prot_table_1.csv` (written by `vignette.qmd:507`) and reuses
`create_overview_table()`.

```yaml
---
title: "Overview of Indel Mutational Signatures"
format:
  html:
    embed-resources: true
    toc: false
    css: styles.css
params:
  separate_pages_dir: "figure/separate_pages"
  table_csv: "prot_table_1.csv"
---
```

Body:

```r
#| label: overview-table
#| echo: false
source("vhelpers.R")
source("table_1_col_name_mapping.R")
sig_table2 <- read.csv(params$table_csv, check.names = FALSE)
create_overview_table(sig_table2, link_base = params$separate_pages_dir)
```

Plus the existing footnote text from vignette.qmd:524-526.

Because `embed-resources: true` makes the HTML standalone, the file can be
moved anywhere as long as `separate_pages_dir` is set correctly relative to
its final location (or to an absolute URL).

### 4. Render wrapper: `vignette/render_overview_table.R`

A small companion to `render_separate_pages.R`, using `argparser` per user
convention:

- `--separate-pages-dir` (default `figure/separate_pages`) — written into the
  rendered HTML's hyperlinks.
- `--table-csv` (default `prot_table_1.csv`).
- `--output` (default `overview_table.html`).

Implementation calls `quarto render overview_table_standalone.qmd -P
separate_pages_dir:<dir> -P table_csv:<csv> --output <out>` via the same
`find_quarto()` helper used in `render_separate_pages.R:19`.

## Verification

1. `Rscript vignette/render_overview_table.R` (from repo root or `vignette/`)
   → produces `overview_table.html` linking to `figure/separate_pages/*.html`.
2. Open with `xdg-open vignette/overview_table.html`; click several signature
   IDs (including ones with Greek letters like InsDel_Aα) and confirm each
   opens the correct per-signature page.
3. Re-render the main vignette (`quarto render vignette/vignette.qmd`) and
   confirm the in-page overview table still works (anchors unchanged because
   `link_base` defaults to `NULL`).
4. Run with a custom directory:
   `Rscript vignette/render_overview_table.R --separate-pages-dir
   ../sigs/pages --output /tmp/overview.html` and confirm the emitted `href`s
   use that path.
