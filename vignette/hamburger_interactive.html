About This Visualization

This page displays hamburger plots (also known as snake plots) showing how mutations attributed to each signature are distributed across cancer types.

How to Use

  1. Select an assignment type: Choose between the 83+89 as 83-type assignments (33 signatures) or the 648-type assignments (44 signatures).

  2. Select a signature: Pick a signature from the dropdown to view its hamburger plot.

  3. Click on a point: Each point represents one tumor. Click on a point to view that tumor’s full mutational spectrum rendered with mSigPlot in ID83, ID89, and ID476 classifications.

  4. View signature decomposition: Click on the sample ID (shown in blue) to see how that tumor’s spectrum is decomposed into constituent signatures. This shows a bar plot of mutation counts assigned to each signature, followed by plots of the individual signatures.

Reading the Hamburger Plot

  • X-axis: Cancer types, ordered by median mutation count (ascending)
  • Y-axis: Number of mutations attributed to this signature (log scale)
  • Points: Individual tumors, spread horizontally within each cancer type column
  • Red dashed lines: Median mutation count for each cancer type
  • Alternating backgrounds: Help distinguish adjacent cancer type columns
